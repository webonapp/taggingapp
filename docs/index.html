Tagging App

Applicazione nativa macOS per analisi video sportiva.

Stato

Il progetto è in sviluppo. Il prototipo include player video, timeline, Code Window, label, note, playlist e importazione sperimentale dei pacchetti Sportscode.

Installazione

Scarica il repository e apri Package.swift con Xcode su macOS 14 o superiore.
